# CampusCareer 🎓

A Smart Internship & Placement Management System designed to connect students with relevant internship and job opportunities.

## 🚀 Features

- Student Registration & Login
- Student Profile Management
- Smart Career Match
- Opportunity Eligibility Checking
- Internship & Job Listings
- Online Application Tracking
- Application Status Updates
- Admin Opportunity Management
- Student Application Management
- MongoDB Atlas Database Integration

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- REST API

## 👥 Project Team

CampusCareer was developed as a team project.

### Student
- Profile management

- Applications and status tracking

### Admin

- View applications
- Update application status
